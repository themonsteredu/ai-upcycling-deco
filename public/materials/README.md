# 부자재 사진을 넣는 곳

1단계(3D 공방)에서 시험해 볼 **부자재 사진**을 여기에 넣어 주세요.
**5~10장** 정도면 충분합니다.

## 파일 이름

자유롭게 지으셔도 되지만, **영어 소문자와 하이픈(-)** 만 써 주세요.
한글 파일 이름은 태블릿 브라우저에서 가끔 깨집니다.

예시:

```
denim-scrap-1.png     (천 조각)
denim-scrap-2.png
button-red.png        (단추)
button-wood.png
eye-round.png         (얼굴 부속 - 눈)
eye-star.png
mouth-smile.png       (얼굴 부속 - 입)
ribbon.png            (기타)
```

## 사진 조건

- **배경이 지워진 투명 PNG**
  - (흰 배경 사진밖에 없으셔도 괜찮습니다. 2단계에서 "흰 배경 지우기" 버튼을 만들 예정입니다)
- **긴 쪽이 500~800 픽셀** 정도
- 부자재 주변의 **빈 여백은 최대한 잘라내 주세요.** 여백이 넓으면 3D에서 붙일 때 실제보다 작아 보입니다.
- 사진마다 가로세로 비율이 달라도 괜찮습니다. 앱이 비율을 읽어서 찌그러지지 않게 붙입니다.

---

2단계에서 선생님 화면(재료함 관리)을 만들면, 그때부터는 이 폴더 대신
**웹에서 끌어다 놓기로 업로드**하게 됩니다. 이 폴더는 1단계 확인용입니다.
