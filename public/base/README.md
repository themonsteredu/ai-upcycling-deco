# 키링 본체 사진을 넣는 곳

여기에 **키링 본체 사진 4장**을 넣어 주세요.
파일 이름을 아래와 **똑같이** 맞춰 주셔야 합니다. (영어 소문자, 띄어쓰기 없음)

| 파일 이름         | 무엇                              |
| ----------------- | --------------------------------- |
| `denim-front.png` | 데님(진한 청바지) — 끈이 **왼쪽**  |
| `denim-back.png`  | 데님(진한 청바지) — 끈이 **오른쪽** |
| `linen-front.png` | 무지 리넨(아이보리) — 끈이 **왼쪽** |
| `linen-back.png`  | 무지 리넨(아이보리) — 끈이 **오른쪽** |

같은 물건을 앞뒤로 찍으면 끈의 위치가 좌우로 바뀝니다.
**끈이 왼쪽에 보이는 쪽을 `front`, 오른쪽에 보이는 쪽을 `back`** 으로 저장해 주세요.
뒷면을 좌우로 뒤집는 일은 앱이 알아서 합니다.

## 사진 조건

- **고리 끈은 사진에 그대로 있어도 됩니다.** 앱이 사진의 모양을 그대로 읽어서
  두꺼운 쿠션 부분은 통통하게, 얇은 끈 부분은 납작하게 부풀립니다. 자르지 않습니다.
- **배경은 지워지지 않아도 괜찮습니다.** 흰 배경으로 찍은 사진을 그대로 넣고
  아래 명령을 한 번 돌리면 배경이 투명해집니다.

  ```
  npm run prepare-base
  ```

  원본은 `_original` 폴더에 자동으로 보관되므로 몇 번을 다시 돌려도 안전합니다.
- 크기는 **긴 쪽이 1200~2000 픽셀** 정도면 충분합니다. 비율은 맞추지 않아도 됩니다.
- 장식이 하나도 없는 **맨 상태**로 찍어 주세요.
- 금속 링이나 손목줄을 함께 찍어도 됩니다. 사진에 찍힌 그대로 나옵니다.

파일을 넣고 앱을 새로고침하면 바로 반영됩니다.
