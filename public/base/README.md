## 사진 조건

- **배경이 지워진 투명 PNG** (장식이 하나도 없는 맨 상태)
- **가로 : 세로 = 2.7 : 2.1** 비율에 맞춰 잘라 주세요.
  - 권장 크기: **가로 1350 × 세로 1050 픽셀**
  - (똑같은 비율이면 1080×840, 2700×2100 등 어떤 크기든 괜찮습니다)
- 고리 끈, 금속 링, 스프링 손목줄은 **사진에 넣지 마세요.** 3D로 따로 만듭니다.
- 뒷면 사진은 **좌우를 뒤집지 말고** 그냥 찍은 그대로 넣어 주세요. 뒤집는 건 앱이 알아서 합니다.
