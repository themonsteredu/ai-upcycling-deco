# 고리 사진을 넣는 곳

키링 끈 끝에 거는 **고리(카라비너)** 사진을 여기에 넣습니다.
여기 넣은 고리는 **모든 학생 화면에 똑같이** 나타납니다.
(학생이 각자 넣는 고리는 그 태블릿에만 남습니다)

## 사진 조건

- **물건 하나만** 찍힌 사진. 옆에 다른 물건이 걸치면 같이 붙어 나옵니다
- 배경은 안 지워도 됩니다. 넣을 때 자동으로 지우고,
  **하트 안쪽처럼 뚫려 있어야 하는 구멍까지 뚫습니다**
- 파일 이름은 영어 소문자와 하이픈으로 (`heart-black.png`)
  → 이 이름이 학생 화면의 고리 이름이 됩니다
- 긴 쪽 500~1000 픽셀이면 충분합니다

## 부자재는 어디에?

키링 표면에 붙이는 부자재는 `public/materials/` 폴더입니다.
