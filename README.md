# 업사이클 키링 디자인

초등 3학년 ~ 중학교 3학년 대상 **진로체험 수업(90분)** 용 웹앱입니다.
학생이 3D로 청바지 업사이클링 키링 설계도를 만들고, 그 설계도를 보며 실제 바느질로 완성합니다.

## 내 컴퓨터에서 열어보는 방법

터미널에 아래를 **순서대로 하나씩** 붙여넣고 엔터를 누르세요.

**처음 한 번만** (필요한 것들을 내려받습니다. 몇 분 걸립니다)

```
npm install
```

**열어볼 때마다**

```
npm run dev
```

그러면 아래 주소가 나옵니다. 브라우저 주소창에 넣으면 화면이 뜹니다.

```
http://localhost:3000
```

끄고 싶을 땐 터미널에서 `Ctrl` + `C` 를 누르세요.

## 사진 넣는 곳

| 폴더                | 무엇을 넣나                            | 안내문                     |
| ------------------- | -------------------------------------- | -------------------------- |
| `public/base/`      | 키링 본체 사진 4장 (데님·리넨 앞뒤)     | `public/base/README.md`      |
| `public/materials/` | 부자재 사진 (천 조각, 단추, 눈알 등)     | `public/materials/README.md` |

사진을 넣은 뒤 `http://localhost:3000` 을 새로고침하면
어떤 사진이 들어왔는지 체크 표시로 확인할 수 있습니다.

본체 사진의 배경이 흰색이면 아래 명령을 한 번 돌려 투명하게 만듭니다.
**사진을 자르지는 않습니다.** 고리 끈도 찍힌 그대로 남습니다.

```
npm run prepare-base
```

## 키링 모양은 어떻게 만들어지나

정해진 사각형 모양을 쓰지 않고, **사진의 실루엣을 그대로 읽어서 부풀립니다.**

- 실루엣 안쪽으로 깊이 들어간 곳(쿠션 몸통) → 통통하게 부품
- 가장자리에 가까운 곳(고리 끈처럼 얇은 부분) → 납작하게 유지

덕분에 사진을 자르지 않아도 끈이 어색하게 튀지 않고, 새로운 모양의 본체를
추가해도 코드를 고칠 필요가 없습니다. 쿠션 몸통의 세로 길이가 항상 2.1이 되도록
전체 크기를 맞추므로, 데님과 리넨의 크기가 저절로 같아집니다.

**3D로 따로 만드는 부속은 없습니다.** 금속 링과 스프링 손목줄을 넣어 봤지만
실물 사진 옆에서 만화처럼 겉돌아 빼기로 했습니다. 화면에는 사진에 찍힌 것만 나옵니다.

## 3D 공방 (`/workshop`)

화면이 셋으로 나뉩니다.

| 자리 | 들어 있는 것 |
| --- | --- |
| 왼쪽 | 원단 고르기(데님·리넨) · 재료함 · **+ 재료 넣기** · 세트 저장/불러오기 |
| 가운데 | 3D 키링. 위에 ① 재료 고르기 → ② 키링 위를 클릭 → ③ 작품 저장 안내 |
| 오른쪽 | 붙인 개수 · 모드(붙이기/떼어내기) · 크기 · 기울기 · 저장 버튼 |

### 재료함

**직접 올린 실물 사진만 씁니다.** 앱이 만들어 주는 도형이나 색칠 기능은 넣지 않았습니다.
학생이 3D에서 만든 것을 실제 바느질로 그대로 만들어야 하므로,
재료함에는 실제로 가지고 있는 부자재만 있어야 합니다.

**+ 재료 넣기** 를 누르면 부자재 사진을 그 자리에서 넣을 수 있습니다.
넣는 순간 **배경을 자동으로 지우고 여백까지 잘라냅니다.**
서버에 올리지 않고 브라우저에 담기므로 새로고침해도 남아 있습니다.

자동 지우기는 사진 **가장자리에서 이어진 배경만** 지웁니다. 그래서
부자재 한가운데의 밝은 반사광이 뚫리지 않고, 배경이 복잡한 사진은
조금만 지워지고 맙니다(망가뜨리지 않습니다).

다만 **옆에 걸친 다른 부자재까지 골라낼 수는 없습니다.** 한 장에 여러 개가
찍혔거나 자동 결과가 마음에 들지 않으면 선생님 화면의
**재료 다듬기(`/teacher/trim`)** 에서 손으로 잘라내고 다듬은 뒤 넣으면 됩니다.
**세트 저장**으로 내려받아 두면 다른 컴퓨터에서 **세트 불러오기**로 그대로 쓸 수 있습니다.

### 고리

키링 끈 끝에 거는 **고리(카라비너)** 를 따로 고를 수 있습니다.
부자재와 달리 한 개만, 정해진 자리에 걸립니다.

- **+ 고리 넣기** 로 사진을 넣으면 배경을 지우면서 **가운데 구멍까지 뚫습니다.**
  하트 카라비너처럼 뚫려 있어야 하는 물건이라 부자재와 다르게 처리합니다.
- 평평한 사진으로 붙이면 옆에서 볼 때 사라지므로,
  키링 본체와 같은 방법으로 **사진 실루엣에 두께를 넣어 3D로** 세웁니다.
- 크기 슬라이더로 조절할 수 있고, 고리까지 화면에 들어오도록 자동으로 맞춰집니다.

### 키링 속 채우기

겉감은 앞장·뒷장 두 겹이라 옆에서 보면 솔기 틈으로 속이 들여다보였습니다.
같은 모양을 조금 작게 한 겹 더 두어 안이 꽉 차 보이게 했습니다.
속살 색은 사진에서 천의 평균 색을 읽어 조금 어둡게 쓰므로 원단이 바뀌어도 따라갑니다.

### 조작 방법

손가락으로 직접 만지는 것과 오른쪽 슬라이더, 둘 다 됩니다.

| 상황                              | 동작                                                                  |
| --------------------------------- | --------------------------------------------------------------------- |
| 아무것도 선택 안 된 상태           | 한 손가락 드래그 → 키링 돌리기 / 핀치 → 화면 확대·축소                  |
| 재료함에서 부자재를 고른 뒤 표면 톡 | 그 자리에 곡면을 따라 기울어져 **붙음**                                 |
| 붙여놓은 부자재를 톡               | **선택됨** (테두리 표시 + 옆에 작은 버튼 `− +` `↺ ↻`)                   |
| 선택된 동안                        | 핀치 → **크기** / 두 손가락 비틀기 → **기울기** / 한 손가락 끌기 → **위치 이동** |
| 빈 곳을 톡                         | 선택 해제 → 다시 키링 돌리기                                            |

- 마우스 노트북에서는 핀치·비틀기가 없으므로, 선택했을 때 뜨는 **작은 버튼**으로 조절합니다.
- 누른 지점과 뗀 지점이 **6픽셀 안쪽일 때만** "톡(클릭)"으로 처리합니다.
  돌리려고 드래그했는데 부자재가 붙어버리는 일을 막기 위해서입니다.
- 크기 범위는 기본값의 **40% ~ 200%**, 기울기는 **0° ~ 360°** 입니다.
- **색상 조절 기능은 넣지 않습니다.** 부자재는 실물 사진이라 색을 바꿀 이유가 없습니다.
- 작업 중인 배치는 브라우저에 자동 저장되어, 뒤로 갔다 와도 날아가지 않습니다.

## 재료 다듬기 화면 (`/teacher/trim`)

찍어 온 부자재 사진의 배경을 앱 안에서 바로 지웁니다. 다른 프로그램이 필요 없습니다.

| 순서 | 하는 일 |
| --- | --- |
| ① 자르기 | 틀을 끌어 부자재 하나만 남김. 정사각형 고정 가능 |
| ② 배경색 찍기 | 스포이드로 지울 색을 콕 찍음. **여러 개 찍을 수 있음** (밝은 쪽·어두운 쪽) |
| ③ 비슷한 정도 | 슬라이더로 얼마나 비슷하면 지울지 조절. 실시간 반영 |
| ③-2 어디까지 지울까 | **구멍까지 뚫기** / **바깥 배경만** 중 선택 |
| ④ 지우개 / 되살리기 | 남은 그림자를 손으로 문질러 지움. 붓 굵기 조절, Ctrl+Z |
| ⑤ 가장자리 다듬기 | 안쪽으로 줄이기(배경색 테두리 제거) + 계단 모양 부드럽게 |
| ⑥ 미리보기 | 체크무늬 · 어두운색 · 밝은색 배경으로 정말 뚫렸는지 확인 |
| ⑦ 확인 | 여백을 잘라낸 투명 PNG로 만듦 |

- 사진 여러 장을 한 번에 넣으면 **한 장씩 차례로** 이 과정을 거칩니다.
- 흰 배경뿐 아니라 **회색·나무 책상 배경**도 지워집니다. 조명 때문에 배경이
  밝은 쪽과 어두운 쪽으로 나뉘면 스포이드로 두 곳을 다 찍으면 됩니다.
### 「구멍까지 뚫기」와 「바깥 배경만」

부자재에 따라 필요한 것이 정반대라서 스위치로 골라 쓰게 했습니다.

| | 하는 일 | 이럴 때 |
| --- | --- | --- |
| 구멍까지 뚫기 | 배경색과 같으면 어디든 지움 | **단추 구멍**을 뚫어야 할 때 |
| 바깥 배경만 | 사진 바깥에서 이어져 들어온 곳만 지움 | 물건 위의 **흰 반사광**이 뚫리면 안 될 때 |

예를 들어 하얀 꽃 단추는 구멍이 배경색이라 「구멍까지 뚫기」가 맞고,
노란 별 단추는 표면의 흰 반사광이 회색 배경과 비슷해서 「바깥 배경만」이 맞습니다.

- 노트북에서 쓰는 화면이라 태블릿 대응은 하지 않았습니다.
- 아직 **저장 기능이 없어** 결과를 컴퓨터로 내려받는 것까지만 됩니다.
  다음 단계에서 Supabase 재료함에 바로 들어가도록 이어붙입니다.
- 비밀번호 잠금도 다음 단계에서 붙입니다.

## 규칙

- **로그인·회원가입 없음.** 학생은 수업코드 6자리 + 닉네임만 입력합니다.
- **개인정보를 받지 않습니다.** 실명·학번·사진 모두 받지 않습니다.
- 사진 업로드는 **선생님만** 할 수 있습니다.
- 선생님 화면(`/teacher`)은 **환경변수에 넣은 비밀번호 하나**로만 잠급니다.
- 브랜드 색: **#0DBDB9** (모아킷 틸)
- 글꼴: **에스코어드림 (S-Core Dream)** — 눈누 공개 주소에서 받아 씁니다.
  학교 인터넷이 그 주소를 막아 두면 기기 기본 한글 글꼴로 자동으로 넘어갑니다.
- 화면에 이모지는 쓰지 않습니다.
