# 업사이클링 키링 3D 공방

초등 3학년 ~ 중학교 3학년 대상 **진로체험 수업(90분)** 용 웹앱입니다.
학생이 3D로 청바지 업사이클링 키링 설계도를 만들고, 그 설계도를 보며 실제 바느질로 완성합니다.

## 내 컴퓨터에서 열어보는 방법

터미널에 아래를 **순서대로 하나씩** 붙여넣고 엔터를 누르세요.

**처음 한 번만** (필요한 것들을 내려받습니다. 몇 분 걸립니다)

```
npm install
```

**열어볼 때마다**

```
npm run dev
```

그러면 아래 주소가 나옵니다. 브라우저 주소창에 넣으면 화면이 뜹니다.

```
http://localhost:3000
```

끄고 싶을 땐 터미널에서 `Ctrl` + `C` 를 누르세요.

## 사진 넣는 곳

| 폴더                | 무엇을 넣나                            | 안내문                     |
| ------------------- | -------------------------------------- | -------------------------- |
| `public/base/`      | 키링 본체 사진 4장 (데님·리넨 앞뒤)     | `public/base/README.md`      |
| `public/materials/` | 부자재 사진 (천 조각, 단추, 눈알 등)     | `public/materials/README.md` |

사진을 넣은 뒤 `http://localhost:3000` 을 새로고침하면
어떤 사진이 들어왔는지 체크 표시로 확인할 수 있습니다.

## 규칙

- **로그인·회원가입 없음.** 학생은 수업코드 6자리 + 닉네임만 입력합니다.
- **개인정보를 받지 않습니다.** 실명·학번·사진 모두 받지 않습니다.
- 사진 업로드는 **선생님만** 할 수 있습니다.
- 선생님 화면(`/teacher`)은 **환경변수에 넣은 비밀번호 하나**로만 잠급니다.
- 브랜드 색: **#0DBDB9** (모아킷 틸)
