# 업사이클링 키링 3D 공방

초등 3학년 ~ 중학교 3학년 대상 **진로체험 수업(90분)** 용 웹앱입니다.

## 내 컴퓨터에서 열어보는 방법

터미널에 아래를 **순서대로 하나씩** 붙여넣고 엔터를 누르세요.

**처음 한 번만** (필요한 것들을 내려받습니다. 몇 분 걸립니다)

```
npm install
```

**열어볼 때마다**

```
npm run dev
```

그러면 아래 주소가 나옵니다. 브라우저 주소창에 넣으면 화면이 뜹니다.

```
http://localhost:3000
```

끄고 싶을 땐 터미널에서 `Ctrl` + `C` 를 누르세요.

## 3D 공방 조작 방법 (확정)

슬라이더 없이 **화면에서 직접 만지는 방식**입니다. 휴대폰 사진에 스티커 붙이는 것과 같습니다.

| 상황                              | 동작                                                                  |
| --------------------------------- | --------------------------------------------------------------------- |
| 아무것도 선택 안 된 상태           | 한 손가락 드래그 → 키링 돌리기 / 핀치 → 화면 확대·축소                  |
| 재료함에서 부자재를 고른 뒤 표면 톡 | 그 자리에 곡면을 따라 기울어져 **붙음**                                 |
| 붙여놓은 부자재를 톡               | **선택됨** (테두리 표시 + 옆에 작은 버튼 `− +` `↺ ↻`)                   |
| 선택된 동안                        | 핀치 → **크기** / 두 손가락 비틀기 → **기울기** / 한 손가락 끌기 → **위치 이동** |
| 빈 곳을 톡                         | 선택 해제 → 다시 키링 돌리기                                            |

- 마우스 노트북에서는 핀치·비틀기가 없으므로, 선택했을 때 뜨는 **작은 버튼**으로 조절합니다.
- 누른 지점과 뗀 지점이 **6픽셀 안쪽일 때만** "톡(클릭)"으로 처리합니다.
  돌리려고 드래그했는데 부자재가 붙어버리는 일을 막기 위해서입니다.
- 크기 범위는 기본값의 **40% ~ 200%**, 기울기는 **0° ~ 360°** 입니다.
- **색상 조절 기능은 넣지 않습니다.** 부자재는 실물 사진이라 색을 바꿀 이유가 없습니다.
- 작업 중인 배치는 브라우저에 자동 저장되어, 뒤로 갔다 와도 날아가지 않습니다.

## 규칙

- **로그인·회원가입 없음.** 학생은 수업코드 6자리 + 닉네임만 입력합니다.
- **개인정보를 받지 않습니다.** 실명·학번·사진 모두 받지 않습니다.
- 사진 업로드는 **선생님만** 할 수 있습니다.
- 선생님 화면(`/teacher`)은 **환경변수에 넣은 비밀번호 하나**로만 잠급니다.
- 브랜드 색: **#0DBDB9** (모아킷 틸)
